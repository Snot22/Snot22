# Lumora — AI Companion

Original AI companion website starter. This repository currently deploys the public landing page and interactive character studio prototype.

## Deploy
Import this repository into Vercel and use the Next.js preset. No environment variables are required for the public preview.

## Current scope
- Responsive dark luxury landing page
- Realistic and anime character style selector
- Interactive character brief builder
- Pricing presentation (illustrative only)

## Before commercial launch
Authentication, persistent storage, AI chat, image generation, voice, Stripe subscriptions, admin authorization, privacy controls, and moderation must be implemented and tested. Do not accept payments until Stripe checkout and webhook verification are complete.
